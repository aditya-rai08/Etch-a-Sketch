# 🎨 Etch-a-Sketch

A simple interactive Etch-a-Sketch drawing application built using **HTML, CSS, and JavaScript**. Draw on a customizable grid, experiment with colors, and create pixel-style artwork directly in your browser.

## ✨ Features

- **Dynamic Grid:** Generate a customizable grid by entering a size between 1 and 100.
- **Color Picker:** Choose your preferred color and paint grid squares.
- **Random Color Mode:** Generate random RGB colors while drawing.
- **Eraser Mode:** Erase individual squares by hovering over them.
- **Interactive Drawing:** Paint the grid by moving your mouse over the squares.
- **Flexible Grid Layout:** Uses CSS Flexbox to arrange grid squares.
- **Clear Grid:** Clear the existing drawing and reset the grid.

## 🛠️ Built With

- **HTML5** — Structure of the application.
- **CSS3** — Styling and Flexbox layout.
- **JavaScript** — Grid generation, DOM manipulation, event handling, and drawing modes.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/aditya-rai08/Etch-a-Sketch.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Etch-a-Sketch
   ```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.

## 🎮 How to Use

1. Click the grid generation button.
2. Enter a number between 1 and 100 to create an \(n \times n\) grid.
3. Choose a color using the color picker.
4. Hover over the grid squares to draw.
5. Activate **Random Color** mode to paint with randomly generated RGB colors.
6. Activate **Eraser** mode to remove colors from individual squares.
7. Switch between modes to experiment with different drawing styles.
